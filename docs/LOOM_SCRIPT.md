# Three-minute Loom recording script

This is a recording plan. It does not claim that a Loom was recorded. Record at normal 1.0x speed in a desktop browser. Use a 1440 by 900 viewport. Keep the cached/live control visible and set it to **Cached**. Close unrelated tabs and notifications before the timer starts.

| Time | Screen action | Narration |
| --- | --- | --- |
| 0:00-0:15 | Start on the split audit view. Hold for two seconds. Point to the two answer columns and the empty Citation Audit panel. | "This is The Hallucination Trap. It is an independent demo. It tests one legal question in two systems at the same time, then makes every citation face the official law." |
| 0:15-0:35 | Point to **Cached**, then to **Ungrounded model** and **Grounded pipeline**. Do not change the mode. | "The left answer is a closed-book model with no retrieval. The right answer uses hybrid search, a cross-encoder, and exact citation verification. Cached mode is visible because this recording must not depend on a model API." |
| 0:35-0:50 | Change the interface to Arabic. Pause so the RTL layout is clear. | "The full interface now changes to Arabic and right-to-left layout. The corpus contains the official Arabic text and its official English translation." |
| 0:50-1:10 | Click the primary Arabic chip about a neighbour's building blocking light. Submit it. Keep both answer columns in view. | "This question asks whether an owner can seek removal of a neighbour's building when it blocks light, and whether an administrative permit changes that private-law right." |
| 1:10-1:32 | Let both answers stream. Follow the citation audit rows as they appear. Do not scroll past the answer headers. | "Both answers arrive at the same time. The ungrounded answer sounds certain. The grounded path can use only retrieved articles. Each detected reference goes through parse, resolve, and exact lookup while the text is still arriving." |
| 1:32-1:55 | Hold on the red **FABRICATED** stamp and its short shake. Point to the reason that the cited article is outside the 1-to-1,422 range. | "There is the failure. The model cited an article that does not exist in this law. The verifier does not say only 'not found.' It identifies the law, states that it has 1,422 articles, and gives the exact reason for the red verdict." |
| 1:55-2:20 | Point to the grounded answer's green verified rows and defensibility score. Open one verified article's official source link in a new tab. | "The grounded answer cites the real provisions. A green result means an exact key match. It also shows the official text excerpt and source. The score is simply verified citations divided by all citations, so it can be reproduced." |
| 2:20-2:45 | On the official UAE Legislation page, show the government domain, article heading, and matching text. Then return to the demo tab. | "This is not a private legal database or a generated source. It is the official UAE Legislation portal. The article number and text match the indexed record, and the link lets a lawyer check the proof independently." |
| 2:45-3:00 | Open `/results`. Hold on the citation metrics and the independence footer until the timer reaches exactly 3:00. | "The results page reads the repository's evaluation file. It reports precision, recall, fabrication rate, and verifier false positives. The standard is simple: catch invented law, and never call real law fake." |

The nine segments total exactly 180 seconds. Stop the recording at 3:00. Do not speed up the narration. If an action is early, hold the relevant proof on screen.
