# Demo storyboard

The two recordings tell the same complete story in different voices. Arabic is written as Gulf business Arabic, not as a literal translation. Both versions use the cached, tested trap so the red verdict is deterministic. The interface keeps the cached indicator visible.

## Story logic

1. **Risk:** one invented article can damage client-ready legal work.
2. **Purpose:** this independent demo catches that failure before it reaches a lawyer.
3. **Problem:** an ungrounded model gives a fluent answer and invents a specific article.
4. **Proof:** the verifier checks the identified law and article. It gives a red verdict with the exact reason.
5. **Solution:** the grounded path retrieves and ranks official law, cites only retrieved evidence, and refuses when confidence is weak.
6. **Contrast:** each lane has a visible citation scoreboard.
7. **Measurement:** the results page reports reproducible evaluation figures and the measured false-positive rate.
8. **Close:** fluent text is not enough; citations must survive the official record.
