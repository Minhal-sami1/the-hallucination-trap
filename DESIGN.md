# The Hallucination Trap — interface system

## Direction

The interface is a forensic workbench. It does not use a marketing hero. The question, the two answers, and the live citation audit are visible in one working surface. The audit rail has the strongest contrast because it is the proof layer.

The visual language is institutional and warm. Warm ivory replaces clinical white. Plum is the primary action color. Navy marks grounded system state. Red is reserved for a confirmed fabricated citation. Green marks an exact corpus match. Amber marks an honest scope limit.

The interface uses no HAQQ logo and makes no affiliation claim.

## Structure

- Macrostructure: Workbench.
- Navigation: N9 edge-aligned utility bar.
- Footer: Ft2 compact evidence and independence bar.
- Data display: F3 tabular evaluation results.
- Seed controls: C1 outlined chips.
- Desktop: question docket above three columns: ungrounded answer, grounded answer, and citation audit.
- Mobile: question docket, answer panels, and audit stack in reading order. The audit is never hidden behind a tab.
- Arabic: the complete grid mirrors. Text, controls, score order, and status placement use RTL layout.

## Typography

- English: Manrope for display and body text. Its geometric rhythm relates to the source
  brand without copying the exact house font.
- Arabic: IBM Plex Sans Arabic for correct shaping and a similar geometric rhythm.
- Numerical data: tabular number features in the same type system.

## Interaction

- Cached/live state is always visible beside the run action. Cached is the default.
- Streaming uses a persistent status line. Each panel states its current pipeline stage.
- A confirmed fabricated citation enters with one short impact shake and a red field flash. It makes no sound.
- Reduced-motion mode removes movement and keeps a firm red border and stamp.
- A grounded refusal is green and is described as a successful control decision.
- API or pipeline failures stay in the affected panel. They do not block the other side.

## Accessibility

- Target WCAG 2.2 AA contrast.
- All controls have visible focus and a minimum 44 px target.
- Verdicts use text and icons in addition to color.
- Live status text uses polite announcements. New fabricated verdicts use an assertive announcement.
- The page supports 320 px through large desktop widths without horizontal page scroll.

## Tokens

The canonical implementation tokens are in `tokens.css`. `DESIGN.json` provides the same decisions as structured metadata.
